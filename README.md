# woowacourse 8기 최종 코딩테스트 미션 - 개발자 비상근무

## 개발자 비상근무 전체 기능구현 목록

- [x] 비상 근무를 배정할 월과 시작 요일을 입력받는다.
    - 예외) 월 입력이 숫자가 아닐 경우
    - 예외) 월 입력이 1에서 12 사이가 아닐 경우
    - 예외) 시작요일이 월,화,수,목,금,토,일 이 아닌경우
    - 예외) 기타 잘못된 입력일 경우
- [x] 평일 비상 근무 순번대로 사원 닉네임을 입력받는다.
    - 예외) 닉네임이 중복 입력된 경우
    - 예외) 5자 초과인 닉네임이 존재할 경우
    - 예외) 닉네임이 5명 미만 혹은 35명 초과일 경우
- [x] 휴일 비상 근무 순번대로 사원 닉네임을 입력받는다.
    - 예외) 닉네임이 중복 입력된 경우
    - 예외) 5자 초과인 닉네임이 존재할 경우
    - 예외) 닉네임이 5명 미만 혹은 35명 초과일 경우
    - 조건) 휴일 순번의 입력 값이 올바르지 않은 경우, '평일 순번'부터 다시 입력 받는다.
- [x] 해당 월의 1일부터 말일까지 크루(비상근무자)를 배정한다.
    - 조건) 주말, 휴일인 경우 휴일 크루 순번 리스트에서 근무자를 배정한다.
    - 조건) 비상근무자는 어떤 경우에도 연속 2일 근무할 수 없다.
    - 조건) 순번 상 특정근무자가 연속 2일 근무하는 상황에는 다음 근무자와 순서를 바꾼다.
- [ ] 해당 월 비상근무표를 출력한다.
    - 조건) 평일이면서 법정공휴일의 경우에만 요일 뒤에 (휴일) 표기를 한다
    - 조건) 비상 근무표 출력을 완료하면 프로그램은 종료된다.
